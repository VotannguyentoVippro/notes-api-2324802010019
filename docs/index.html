2. Đối chiếu 5 đặc tính điện toán đám mây theo NIST

  • 1. Tự phục vụ theo yêu cầu (On-demand self-service): Khởi tạo môi trường lập trình Codespace ngay lập tức chỉ bằng một cú nhấp chuột mà không cần sự can thiệp hay phê duyệt thủ công từ quản trị viên hệ thống.
  • 2. Truy cập mạng rộng rãi (Broad network access): Mở IDE và viết mã trực tiếp qua trình duyệt web từ bất kỳ thiết bị nào; mở cổng 3000 để điện thoại di động truy cập trực tiếp API qua mạng Internet.
  • 3. Gộp tài nguyên (Resource pooling): Máy ảo Codespace được cấp phát từ hạ tầng máy chủ dùng chung của Microsoft Azure/GitHub, phân chia tài nguyên động cho hàng ngàn người dùng độc lập.
  • 4. Co giãn nhanh chóng (Rapid elasticity): Có thể nâng/hạ cấu hình máy ảo (từ 2 cores lên 4 hoặc 8 cores) hoặc mở rộng thêm máy ảo mới khi cần và giải phóng tức thì khi ngừng sử dụng.
  • 5. Dịch vụ đo lường được (Measured service): Hệ thống tự động ghi nhận chính xác từng phút máy hoạt động, tính toán chi phí theo số lượng Core-hours sử dụng trong mục GitHub Billing.
